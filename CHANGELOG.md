# Histórico de Versões - Hotel Manager

Este arquivo acompanha o painel de "Novidades" exibido dentro do sistema.
A cada nova versão, adicione um bloco no topo desta lista E no array `CHANGELOG`
dentro do `index.html`, mantendo os dois em sincronia.

Cada versão deve ter a data real do dia em que a atualização foi feita
(campo `data` no formato AAAA-MM-DD dentro do array). Uma atualização por dia.

Tipos de mudança:
- **Novo**: funcionalidade nova
- **Correção**: correção de erro/bug
- **Melhoria**: ajuste ou aprimoramento do que já existia

IMPORTANTE: o changelog é visível para o cliente. Nunca incluir informações
sensíveis como credenciais (login/senha), dados de usuários, chaves, ou
detalhes técnicos internos. Descrever apenas o benefício de forma clara.
